# ACF Configuration для Gavrylivka School Theme

## Установка ACF полей

### 1. Hero Section Fields

Файл: `hero-section-fields.json`

**Импорт:**
1. Идите в админку WordPress: **Custom Fields → Tools**
2. Выберите **Import Field Groups**
3. Загрузите файл `hero-section-fields.json`
4. Нажмите **Import**

**Созданные поля:**
- `hero_title` - Заголовок секции
- `hero_subtitle` - Подзаголовок
- `hero_primary_button_text` - Текст главной кнопки  
- `hero_primary_button_link` - Ссылка главной кнопки
- `hero_secondary_button_text` - Текст второй кнопки
- `hero_secondary_button_link` - Ссылка второй кнопки
- `hero_gallery` - Галерея изображений для слайдера

**Настройки слайдера:** Автоплей всегда включен, скорость 3.5 секунды (зафиксировано в коде)

### 2. Где найти поля

После импорта поля появятся при редактировании страницы с шаблоном "Головна" (home.php).

### 3. Fallback значения

Если ACF поля не заполнены, используются значения по умолчанию:
- Заголовок: "Gavrylivka School"
- Подзаголовок: "Сучасна освіта для майбутнього вашої дитини"
- Кнопка 1: "Дізнатися більше" → "#about"
- Кнопка 2: "Зв'язатися з нами" → "tel:+380671234567"
- Слайдер: автоплей включен, скорость 3.5 секунды

### 4. Обратная совместимость

Код поддерживает старые поля `main_banner_1`, `main_banner_2`, `main_banner_3` если новое поле `hero_gallery` не заполнено.

### 2. Team Page Fields (ACF Free Compatible)

Файл: `team-fields.json`

**Импорт:**
1. Идите в админку WordPress: **Custom Fields → Tools**
2. Выберите **Import Field Groups**
3. Загрузите файл `team-fields.json`
4. Нажмите **Import**

**Совместимость:** ✅ Работает с **бесплатной версией ACF** (не требует ACF PRO)

**Структура полей:**

Поля организованы как **фиксированный набор** для 6 сотрудников:

**Секція 1: Адміністрація (до 6 осіб)**
- `admin_section_title` - Название секции (по умолчанию: "Адміністрація")

**Для каждого администратора (1-6):**
- `member_X_photo` - Фото работника (Image)
- `member_X_name` - ПІБ
- `member_X_position` - Посада
- `member_X_description` - Описание, опыт, достижения (Textarea)
- `member_X_email` - Email для контакта (опционально)
- `member_X_phone` - Телефон для контакта (опционально)

где `X` = 1, 2, 3, 4, 5, 6

**Секція 2: Педагогічний колектив (до 25 осіб)**
- `teachers_section_title` - Название секции (по умолчанию: "Педагогічний колектив")

**Для каждого учителя (1-25):**
- `teacher_X_photo` - Фото вчителя (Image)
- `teacher_X_name` - ПІБ
- `teacher_X_position` - Посада/Предмет викладання
- `teacher_X_description` - Описание, опыт

где `X` = 1, 2, 3, ..., 25

**Примечание:** У учителей нет полей Email и Телефон - только базовая информация.

**Где найти:**
После импорта поля появятся при редактировании страницы с шаблоном **"Team"** (page-team.php).

**Как использовать:**
1. Создайте новую страницу или откройте существующую
2. Выберите шаблон **"Team"**
3. **Секція Адміністрація**: Заполните до 6 сотрудников с контактами (email, телефон)
4. **Секція Педагогічний колектив**: Заполните до 25 учителей (без контактов)
5. Загрузите фото, заполните ПІБ, посаду, опис
6. Незаполненные слоты автоматически скрываются на странице

**Как это выглядит:**
- Если заполнены только администраторы - показывается только секция "Адміністрація"
- Если заполнены только учителя - показывается только секция "Педагогічний колектив"  
- Если заполнены оба - показываются обе секции одна под другой

**Fallback значения:**
Если ACF поля не заполнены, показываются 3 тестовые карточки с дефолтными данными администрации.

**Фото по умолчанию:**
Если фото не загружено, используется красивый градиентный аватар (`default-avatar.svg`).

## Требования

- ✅ **Advanced Custom Fields** (бесплатная версия) - достаточно для всех функций
- WordPress 5.0+

**Примечание:** Hero Section может использовать Gallery field (доступно в ACF Free), а Team Page использует только базовые типы полей (Text, Textarea, Image, Email), которые есть в бесплатной версии.

## Примечания

- Все конфигурации включают валидацию и подсказки для редакторов
- Используйте квадратные изображения для фото сотрудников (рекомендуется 600x600px)
- Контактные данные отображаются с иконками для лучшей визуализации
- **Team Page** поддерживает:
  - До 6 администраторов с контактами (email, телефон)
  - До 25 учителей без контактов
  - Обе секции независимы и отображаются только при заполнении

### 3. Agenda (Schedule) Page Fields (ACF Free Compatible)

Файл: `agenda-fields.json`

**Импорт:**
1. Идите в админку WordPress: **Custom Fields → Tools**
2. Выберите **Import Field Groups**
3. Загрузите файл `agenda-fields.json`
4. Нажмите **Import**

**Совместимость:** ✅ Работает с **бесплатной версией ACF** (не требует ACF PRO)

**Созданные поля:**
- `agenda_monday` - CSV файл для понеділка (max 2MB)
- `agenda_tuesday` - CSV файл для вівторка (max 2MB)
- `agenda_wednesday` - CSV файл для середи (max 2MB)
- `agenda_thursday` - CSV файл для четверга (max 2MB)
- `agenda_friday` - CSV файл для п'ятниці (max 2MB)

**Как использовать:**
1. Создайте новую страницу или откройте существующую
2. Выберите шаблон **"Agenda"**
3. Загрузите CSV файлы для каждого дня недели (можно загрузить не все дни)
4. Нажмите **Publish** или **Update**

**Формат CSV файла:**
- Первая строка должна содержать заголовки колонок
- Остальные строки - данные расписания
- Разделитель - запятая (`,`)
- Кодировка - UTF-8

**Пример CSV (расписание для одного дня):**
```csv
Клас,№ уроку,Час,Предмет,Викладач
5-А,1,8:30-9:15,Математика,Іваненко О.П.
5-А,2,9:25-10:10,Українська мова,Петренко М.І.
5-А,3,10:20-11:05,Англійська мова,Сидоренко Л.В.
6-Б,1,8:30-9:15,Історія,Коваленко В.С.
6-Б,2,9:25-10:10,Математика,Іваненко О.П.
```

**Как это работает:**
- Табы створюються для днів тижня: Понеділок, Вівторок, Середа, Четвер, П'ятниця
- Кожен таб відображає окрему таблицю (свій CSV файл)
- Якщо файл для певного дня не завантажено, таб не відображається
- Таблиця може містити будь-які колонки (клас, час, предмет, викладач тощо)

**Особенности:**
- Таблица автоматически адаптируется под размер экрана
- На мобильных устройствах доступен горизонтальный скролл
- Стильный дизайн с градиентными заголовками
- Чередующиеся цвета строк для лучшей читабельности
- Hover эффект при наведении на строку

**Где найти:**
После импорта поля появятся при редактировании страницы с шаблоном **"Agenda"** (page-agenda.php).

**Примечание:** Если CSV файл не загружен, администраторы увидят предупреждающее сообщение. Посетители сайта увидят только введенный контент страницы.
